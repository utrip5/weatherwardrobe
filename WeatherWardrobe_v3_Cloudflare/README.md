# WeatherWardrobe v3

## Загрузка в GitHub / Cloudflare

1. Распакуйте архив.
2. Откройте репозиторий `utrip5/weatherwardrobe`.
3. Замените старые `wrangler.jsonc`, `package.json`, папки `public` и `src`.
4. Commit changes.
5. Дождитесь Cloudflare Deployment → Success.
6. Откройте ваш `https://...workers.dev`.

## Что входит

- PWA для Android/iPhone.
- Cloudflare Worker: компьютер пользователя не нужен.
- Геокодирование с выбором существующего города.
- Текущая погода + 7 дней.
- Температура и ощущаемая температура.
- Влажность, осадки, вероятность дождя.
- Скорость/направление/порывы ветра.
- UV и видимость.
- Русский/English.
- Мужской/женский режим.
- Расширенный каталог одежды и обуви.
- Лето/Зима/Демисезон/Всесезонная.
- Оценка вещей 0–100: тепло, дождь, ветер, воздухопроницаемость, влагоотвод, лёгкость, переносимость жары, UV.
- Рекомендации используют вещи пользователя.
- Специальная логика для 28°C+ и душной погоды.
- Security headers и валидация входных данных.
- Service Worker.

Гардероб хранится локально на устройстве. Для синхронизации между устройствами следующим этапом можно подключить Cloudflare D1 и авторизацию.

## Android

Откройте HTTPS-сайт в Chrome → меню → Установить приложение / Добавить на главный экран.

## iPhone

Откройте HTTPS-сайт в Safari → Поделиться → На экран Домой.
